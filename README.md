# SkillBridge AI

> An intelligent skill-gap analysis system that helps students identify the skills they need to develop for their target career role.

## Overview

SkillBridge AI is a Python-based AI/ML project designed to solve a real-world career development problem: understanding the gap between a student's current skills and the skills required for a target job role.

The system analyzes a student's existing skills, compares them with the requirements of a selected job role, calculates a skill-match percentage, identifies missing skills, and recommends what the student should learn next.

## Problem Statement

Students often know the career role they want but do not know exactly which skills they are missing.

SkillBridge AI addresses this problem by providing a structured, data-driven approach to skill-gap analysis.

## Key Features

- Analyze a student's existing technical skills
- Compare skills against job-role requirements
- Calculate skill-match percentage
- Identify missing skills
- Recommend skills to learn
- Load job-role requirements from a structured dataset
- Modular Python architecture
- Dependency management using `requirements.txt`
